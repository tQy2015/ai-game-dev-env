# 安全に使うための約束と、AIとの付き合い方

この手順書は、生成AIを使ったゲーム制作環境を学生が導入するためのものです。**セキュリティ面の検証はまだ済んでいません。** 次の約束を守って使ってください。

## 1. 使い方の約束（安全）

- **長時間の自走はさせない。** AIに数時間まかせきりにしない。作業は短く区切り、区切りごとに自分で結果を確認する。
- **夜間やバッチの自動実行は、教員の許可があるまでしない。**
- **教員の指導のもとで使う。** 導入の初回、削除、権限の変更、外部へのデータ送信、ネットワークを使う操作は、教員の前で行う。
- **秘密情報を扱わない。** パスワード、トークン、APIキー、個人情報、アカウントの詳細は、AIとのやり取りに貼らない。ファイルにも書かない。
- **分からない操作は実行しない。** AIが提示したコマンドの内容が分からない場合は、実行前に教員か周りの人に聞く。

## 2. 生成物との付き合い方（品質）

- **動くことと、正しいことは別です。** AIが作ったものは、必ず自分で中身を確かめる。
- **自分のスケッチやコンセプトを、品質の基準（ゲート）にする。** AIの案が、自分の狙いに合っているかを判断するのは、あなたです。
- **AIの案は採否を決めてから使う。** 「採用・保留・却下」を、理由と一緒にメモする。

## 3. AIとの共創（目指す関係）

- AIを「答えを出す機械」ではなく、**対話する相手**として使う。
- 進め方の例:
  1. 自分の狙いを、スケッチやメモで言葉にする。
  2. AIに案を出してもらう。
  3. 案を自分の基準で批評する（何がよく、何が違うか）。
  4. 批評をAIに返し、修正してもらう。
  5. 最後の判断は自分が行う。
- この往復を通じて、自分の考えが明確になっていくことを目指します。

## 4. 記録

- 何を頼み、何を採用し、何を捨てたかを、短くメモする。
- 後で振り返れるように、作業の日付も書く。

## 5. この手順書の位置づけ

- 授業での導入を支えるための教材であり、安全性や動作を保証するものではありません。
- 「未検証」と書いてある箇所は、実機での確認が済んでいません。
