# 05. Maya 2026 の導入と動作確認（Windows・GUI）

**この文書は、学校の方針で Maya を使う場合だけ使ってください。**

**読者**: 学生ではなく、**サポートの LLM（AI）が読んで作業する**ための手順書です。学生は、AI の指示に従い、ログインやダイアログの操作を行います。

**状態ラベル**: 【二次情報】は大学や公式以外の情報（未確認）。【未検証】は学生機で一度も通していない内容。【要確認】は、版やパスが学校の環境で異なる可能性がある内容です。

## 0. 方針（AI が守ること）

1. **操作は GUI で行う。** 外部からの自動操作（commandPort、スクリプトによる遠隔制御、mayapy の一括実行）は、この手順では行いません。セキュリティの検証が済んでいないためです。
2. **サインイン、利用規約、ライセンスの画面は、AI が操作しない。** 学生本人が行い、AI は「何が出ているか」を聞いて、次の手順を案内します。
3. **ダイアログを、閉じる・無視する・突破する操作をしない。** 出たら止めて、学生に内容を伝えます。
4. **個人情報を書き出さない。** アカウント名、メールアドレス、学校の ID、ライセンスのシリアル番号は、報告にもファイルにも書きません。
5. **作業は段階ごとに確認を取る。** 次の段階に進む前に、学生の「完了」の返答を待ちます。

## 1. 事前確認（AI が学生に聞く）

- Windows の版（10 または 11、64bit であること）。
- 空き容量（Maya の導入には大きな容量が必要です。【要確認】）。
- 学校の案内にある、Autodesk の教育アカウント（学生本人が用意する）。
- 学校の指定の版（この手順は Maya 2026 を前提とします。【要確認】）。

**どれかが不明なら、先へ進まずに学校の担当に確認してもらう。**

## 2. インストール（学生が操作し、AI が案内）

1. 学生が、Autodesk の教育向けのページから、Maya 2026 の Windows 版をダウンロードする。
2. インストーラーを学生が実行する。利用許諾の画面は、学生本人が読んで同意する。
3. 途中で、サインインや利用の確認が出たら、**学生本人が行う。** AI は操作しない。
4. インストールが終わったら、学生に「完了」を返してもらう。

**AI の確認**（PowerShell で、読み取りだけ行う）:

```powershell
Test-Path "C:\Program Files\Autodesk\Maya2026\bin\maya.exe"
```

- `True` なら、インストールの場所は確認できています。`False` なら、学生に `C:\Program Files\Autodesk` の下のフォルダ名を教えてもらい、場所を確認します。
- 場所は、学生の作業記録にだけ書きます。ファイル名や場所のうち、個人を特定できる部分（ユーザー名を含むパス）は書きません。

## 3. 初回起動とライセンスの確認（学生が操作）

1. 学生が、スタートメニューから **Autodesk Maya 2026** を起動する。
2. 初回は、ライセンスの確認やサインインの画面が出ることがあります。**学生本人が操作する。**
3. Maya の画面（ビューポート）が開いたら、学生に「開いた」と返してもらう。
4. 上部メニューの **Help → About Maya** で、版の表示を学生に読み上げてもらう（AI は読み上げた内容だけを記録する）。

**止まる条件**: ライセンスのエラー、ログインの失敗、ダイアログの繰り返し。→ AI は手順を進めず、学生に学校の担当へ相談してもらう。

## 4. 動作確認（学生が GUI で行い、AI が手順を案内）

1. メニュー **Create → Polygon Primitives → Cube** で、立方体を 1 つ作る。
2. メニュー **File → Save Scene As** で、作業フォルダ（例: `Documents\maya-test`。個人の名前を含まない名前にする）に、`test-cube.ma` と名前をつけて保存する。
3. 保存したファイルが、フォルダにあることを確認する（エクスプローラーで学生に確認してもらう）。
4. 最後に、**File → Open Scene** で同じファイルを開き直し、立方体が残っていることを確認する。

**完了の判定**: 保存したファイルが開けて、立方体が残っている。→ 「動作確認 OK（GUI）」と記録する。

## 5. 作業の記録（AI が行う）

- 記録は、作品フォルダの `STATE.md` に、次の 4 点だけを書く（個人情報は書かない）。
  - 導入の日付
  - Maya の版（Help → About Maya の表示）
  - 動作確認の結果（OK または未確認）
  - 未解決の項目
- 記録の書き方は、[03-claude-code.md](03-claude-code.md) の STATE.md の例に従う。

## 6. 学生向けの注意

- Maya の作業ファイル（`.ma`）は、Git に入れるかどうかを先生と決める。大きくなる場合は、[04-unity.md](04-unity.md) の §7-5 と同じ考え方で扱う。
- 生成 AI に Maya の操作を頼むときも、[safety-and-co-creation.md](safety-and-co-creation.md) の約束に従い、先生の前で行う。

## 7. 未検証と、今は扱わないこと

- **未検証（学生機）**: 上の 1〜5 の手順は、Windows の学生機で一度も通していません【未検証】。
- **扱わないこと**:
  - commandPort（127.0.0.1:7001 など）による外部からの接続。認証がなく、同じマシンの全プロセスから接続できるため、学生向けには使わない。
  - mayapy による一括生成。Windows での実績がない【未検証】。
- 将来、教員の指導のもとで検証が済めば、この節を改訂します。
