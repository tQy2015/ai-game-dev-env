# 05. Maya で作業する（Windows）

**前提**: Maya 2026 の導入と、サインイン（ライセンスの有効化）が**済んでいること**。授業の案内に従って、先に済ませてください。Maya が起動できない場合は、先生に相談してください。

**この文書は、学校の方針で Maya を使う場合の手順です。** 状態ラベル: 【未検証】は、学生機で一度も通していない内容です。

## 1. 作業の流れ

1. 作品フォルダを作り、Maya のプロジェクトに指定する
2. 3D モデルを作る（立方体から始める）
3. 保存する
4. Unity で使えるように書き出す（FBX）
5. 結果を確かめて、記録する

## 2. 作品フォルダを作り、プロジェクトに指定する

1. エクスプローラーで、作品フォルダを作る（例: `Documents\my-maya-work`）。名前に、自分の名前や学校の ID を入れない。
2. Maya を起動する。
3. メニュー **File → Set Project** で、作品フォルダを選ぶ。
4. Maya は、フォルダの中に `scenes`、`sourceimages`、`images` などを作ります。そのまま使ってください。

**プロジェクトに指定すると、ファイルの保存先が決まります。** 指定しないまま保存すると、探せなくなることがあります。

## 3. 立方体を作る（基本の操作）

1. メニュー **Create → Polygon Primitives → Cube** を選ぶ。
2. 画面の左のツールバーで **Move**（移動）を選び、立方体をドラッグして動かす。
3. **Scale**（拡大縮小）で大きさを変える。
4. 数値で正確に動かしたい場合は、右の **Channel Box**（チャンネルボックス）の値を直接入力する。

**ヒント**: 間違えたら **Ctrl + Z**（元に戻す）。

## 4. 保存する

1. メニュー **File → Save Scene As** を選ぶ。
2. 保存先が、作品フォルダの `scenes` になっていることを確認する。
3. 名前を付けて保存する（例: `cube-01`）。ファイルの形式は `.ma`（Maya ASCII）です。

**定期的に保存**: 作業の区切りごとに、**Ctrl + S** で保存してください。

## 5. Unity で使うために書き出す（FBX）

1. メニュー **File → Export Selection** を選ぶ（書き出すものを先に選択しておく）。
2. ファイルの形式は **FBX export** を選ぶ。
3. 作品フォルダに保存する（例: `cube-01.fbx`）。
4. Unity の [04-unity.md](04-unity.md) の手順で、Unity の `Assets` に入れる。

## 6. Git に入れる場合

- Maya のファイルは、作品フォルダの `.gitignore` で、次を除外します。

```gitignore
# Maya の自動保存と一時ファイル
*.autosave
*.tmp
*.bak
```

- `scenes` の `.ma` と、書き出した `.fbx` は、先生と相談して Git に入れるか決めます（大きくなる場合は [04-unity.md](04-unity.md) の §7-5 を参照）。

## 7. 作業のルール（学生向け）

- **個人情報を、作品フォルダに置かない。** 住所、電話番号、学校の ID などは書かない。
- **操作中は画面を見ておく。** 確認のダイアログが出たら、内容を読んでから操作する。
- **長い時間、自動で動かし続けない。** 作業は区切って、結果を自分で確かめる。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 保存したファイルが見つからない | File → Set Project で、作品フォルダが指定されているか確認する |
| 動かしたものが元に戻らない | Ctrl + Z で戻す。戻らなければ、直前に保存したファイルを開き直す |
| エラーのダイアログが出る | 内容を写真に撮って、先生に見せる |
| Maya が重い | 作業中のシーンを保存してから、Maya を開き直す |

## 8. AI と接続する（任意・教員の指導のもとで）

AI（Claude Code など）から Maya を操作する場合だけ行います。接続口（ポート 7001）は認証がなく、同じパソコンの他のプログラムからも接続できます。**使い終わったら必ず閉じてください。**

1. 作品フォルダに `open_port.mel` を作り、次の 1 行を保存する。
   ```mel
   python("import maya.cmds as cmds; cmds.commandPort(name=':7001', sourceType='python', echoOutput=True)");
   ```
2. Maya を、このファイルを読み込んで起動する（例: `maya.exe -script open_port.mel`。【未検証（Windows）】）。
3. AI に「Maya に接続して、立方体を作って」と頼む。
4. 終わったら、Maya の Script Editor（Python タブ）で次を実行して閉じる。
   ```python
   import maya.cmds as cmds
   cmds.commandPort(name=":7001", close=True)
   ```

接続できないときは [faq.md](faq.md) を見てください。

## 9. 未検証の項目

- この手順は、学生機の Windows で、まだ一度も通していません【未検証】。
- 書き出し（FBX）の設定の名前は、版によって違うことがあります。違う場合は、先生に確認してください。
