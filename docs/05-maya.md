# 05. Maya 2026 の導入（Windows）

**この文書は、学校の方針で Maya を使う場合だけ読んでください。**

**状態ラベル**: 【二次情報（大学の案内など）】は、公式の情報で確認していない内容です。【未検証】は学生機で一度も通していない内容です。ライセンスの条件は変わることがあるため、必ず学校の案内を確認してください。

## 1. 前提【二次情報】

- Maya は 64bit 版のみ。Windows 10 と 11 の 64bit が対象。
- 学生向けの教育ライセンスがあるとされる（期間や更新の条件は学校によって異なる）。学生の資格の確認が必要な場合があります。
- ライセンスの種類（指名ユーザーなど）は、年度や学校の契約で変わります。**学校の情報システム担当に確認してください。**

## 2. 導入の流れ【未検証】

1. Autodesk の教育向けの案内から、学生用のアカウントでサインインする。
2. Maya 2026 の Windows 版をダウンロードする。
3. インストーラーを実行し、利用許諾に同意する。
4. Maya を起動し、同じアカウントでサインインしてライセンスを有効にする。

- ライセンスが認識されない場合は、学校の担当に相談してください。

## 3. この手順書で扱わないこと

- Maya を外部から自動操作する仕組み（スクリプトや、ネットワークからの接続）は、この手順書では扱いません。セキュリティの検証が済んでいないためです。
- 生成AIに Maya の操作を頼むときも、[safety-and-co-creation.md](safety-and-co-creation.md) の約束に従い、先生の前で行ってください。
