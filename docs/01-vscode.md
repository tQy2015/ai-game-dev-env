# 01. VSCode の導入（Windows）

**前提**: Windows 10（1809以降）または 11。VSCode を入れる作業は、学生本人が行う。

## 1. VSCode の本体をインストールする

1. [code.visualstudio.com](https://code.visualstudio.com/) から Windows 用のインストーラーを取得する。
2. インストーラーを実行する。既定の設定で進めてよい。
3. **「Add to PATH」にチェックが入っていることを確認する。** 後でターミナルから `code` を使うために必要です。
4. インストール後、VSCode を起動して、正常に開くことを確認する。

## 2. 統合ターミナルを確認する

1. メニューの **Terminal → New Terminal** を開く（ショートカットは `Ctrl` + `` ` ``）。
2. ターミナルが画面の下に開くことを確認する。
3. 右上のプルダウンで、既定のシェルが **PowerShell** になっていることを確認する。

以降の手順は、この統合ターミナルで行います。

## 3. インストール後の注意（重要）

- VSCode の統合ターミナルは、**VSCode を起動した時点の PATH** を引き継ぎます。
- 後からインストールしたツールは、VSCode を**完全に終了して起動し直す**まで見つかりません。「Reload Window」やターミナルの開き直しでは足りないことがあります。
- 見つからないツールの対処は [cli-path.md](cli-path.md) を参照してください。

## 4. 日本語化（任意）

1. 左のサイドバーの拡張機能（四角が4つ並んだアイコン）を開く。
2. 「Japanese Language Pack for Visual Studio Code」を検索してインストールする。
3. 右下に出る **Restart** を押して再起動する。

英語の画面のままでも問題ありません。公式ドキュメントを検索するときは、英語の方が探しやすいこともあります。
