# 06. 自然言語でシーンにアセットを配置する（Unity・Maya 共通・任意）

**前提**: [04-unity.md](04-unity.md)・[05-maya.md](05-maya.md) が終わっていること。この文書は**応用**です。やらなくても授業は進められます。

**状態ラベル**: この文書の内容は、教員側の検証機（Windows・2026-11-18）で一度確認したものです。学生機では、まだ一度も通していません【未検証】。うまくいかない場合は先生に相談してください。

## 1. これは何か

Unity や Maya のシーンに置くオブジェクト（立方体・球・配布された3Dモデルなど）を、**AI に日本語で頼んで配置してもらう**機能です。やり方は、やさしい順に3つあります。

1. **CSVで配置**（§3）: 座標とアセット名を表（CSV）で指定する。一番確実。
2. **ランダムな配置**（§4）: 「だいたいこの辺に、何個くらい」で頼む。
3. **自然言語で自由に配置**（§5）: 「空き地に木を3本くらい適当に」のように、ふわっと頼む。一番自由だが、結果のばらつきも大きい。

どれも、AI がすべて自動でやるのではなく、**最後は自分の目で確認する**ことが前提です（§8）。

## 2. 共通の仕組み（Unity・Mayaどちらも同じ）

UnityとMayaは別のソフトですが、AIが配置を行う仕組みは同じ3段階です。

| 段 | Unity | Maya |
|---|---|---|
| ① 裏側でスクリプトを実行する | Unity Editor を `-batchmode` で起動し、指定したメソッドを実行する | `mayapy`（画面を開かずにPythonを実行する仕組み）を使う |
| ② オブジェクトを置く | Unity の Editor 機能でオブジェクトを作る | Maya の `cmds` 機能でオブジェクトを作る |
| ③ 保存し、自分の目で確認する | シーンを保存し、Unity を通常モードで開き直す | ファイルを保存し、Maya で開き直す |

**①②は裏側（画面に出ない）、③で初めて画面に出ます。** 「AIに頼んだのに画面に何も変わってない」と感じたら、③の「開き直す」を頼んでいるか確認してください（[faq.md](faq.md)も参照）。

## 3. CSVで配置する（最初に試す）

一番確実なやり方です。**何を・どこに置くかを、先に表で決めてから**AIに頼みます。

1. 配置したいものを、こういう表（CSV）にする。

   ```csv
   name,x,y,z,rotation_y
   Tree_Pine_01,0,0,0,0
   Tree_Pine_01,2,0,1,45
   Rock_Small_02,-1,0,3,0
   ```

2. AIに頼む例:「このCSV（`placement.csv`）の内容で、シーンにアセットを配置して」

3. 結果を、Unity/Mayaの画面を開いて確認する。

**向いている場面**: 配置場所をきっちり決めたい、何度も同じ配置をやり直したい、配置する前に人間がレビューしたい。

## 4. ランダムな配置を頼む

場所を1つずつ決めるのが面倒なときは、範囲と個数を指定して「あとはランダムに」と頼めます。

**指示の例**:「x: 0〜10、z: 0〜10 の範囲に、`Tree_Pine_01` を5本、ランダムな位置と向きで配置して」

- **範囲（x・zの最小値〜最大値）を必ず指定する。** 指定しないと、AIが適当な範囲を決めてしまい、思わぬ場所に飛んでいることがあります。
- 個数も指定する（「何本か」ではなく「5本」）。
- 結果は必ず画面で確認する。重なっていたり、地面の外に出ていることがあります。

## 5. 自然言語で自由に配置する（応用）

「空き地に木を3本くらい適当に」のように、具体的な座標や個数を指定せずに頼むこともできます。ただし、結果の精度は次の2つの掛け算で決まります。

1. **AI側の能力**（自然言語の理解・配置の妥当性の推論）
2. **アセット側の分かりやすさ**（名前・タグがどれだけ具体的か）

このうち、**②の方が自分でコントロールしやすい変数です。** `Cube (1)` のような名前のアセットが多いと、AIが何を配置すればいいか分からず、結果がブレます。配布された素材・自分で作った素材の名前は、`Tree_Pine_01` のように**具体的に**しておくと、自然言語での指示がうまく通りやすくなります。

## 6. Unityでやってみる

1. Unity CLI・Editorの基本は [04-unity.md](04-unity.md) を先に終わらせておく。
2. AIに頼む例:「このUnityプロジェクトに、球を1個作ってシーンに置いて、保存して」
3. 確認する:「保存したシーンを Unity で開いて見せて」

**注意**: 裏側（`-batchmode`）で作ったシーンは、Unityを開いても自動では表示されません。[faq.md](faq.md)の「AIに作ってもらった新しいシーンが、Unityを開いても出てこない」を参照してください。

## 7. Mayaでやってみる

1. Mayaの基本は [05-maya.md](05-maya.md) を先に終わらせておく。
2. [05-maya.md](05-maya.md) §9「AI と接続する」の**方法A（mayapy）**を使う。
3. AIに頼む例:「Mayaのmayapyを使って、球を1個作って、作品フォルダのscenesに保存して」
4. 確認する:「保存したファイルをMayaで開いて見せて」。確認が終わったらMayaを終了する（ライセンスの枠を空けるため）。

## 8. 結果の確認は自分の目で（品質ゲート）

AIに配置を何度もやり直してもらう（ループさせる）こともできますが、**合格・不合格を決めるのはAIではなく、あなた自身です。**

- **先に「どうなっていれば合格か」を決めておく。** 例: 参考になる画像を1枚用意する、「木が重なっていない・空き地から出ていない」のように文章で条件を書く。
- その基準に対して「合うか合わないか」を確認し、合わなければ直す、というやり直し自体はAIに任せてよい。ただし**やり直しの回数には上限を決める**（例: 3回まで）。
- **やり直している間も、画面を見ておく。** 承認が毎回要らないからといって、席を離れて完全に放置する使い方はしないでください（[safety-and-co-creation.md](safety-and-co-creation.md)の「操作中は画面を見ておく」「長時間の自走はさせない」と同じ考え方です）。

## 9. 困ったとき

- 画面に何も変わっていない: §2・[faq.md](faq.md)を参照。
- 配置が思っていた場所と違う: §4のように範囲・個数を具体的に指定し直す。
- Unityのライセンスエラー・Mayaの複数PC制限: [faq.md](faq.md)を参照。
